# Функциональность

## i18n (мультиязычный интерфейс)

4 языка: RU, EN, KZ, IT. Автодетект из `navigator.language`, персистенция в localStorage.

- **Система**: лёгкий словарь без внешних зависимостей — `frontend/src/i18n/translations.ts` (~250 ключей)
- **React**: хук `useT()` для компонентов, `getT()` для non-React контекста (api.ts, store.ts)
- **Переключатель**: dropdown в шапке, текущий код языка (RU/EN/KZ/IT)
- **Конфигурация**: `LOCALE_TRANSLATION_LANGUAGES` в `constants.ts` — управление доступностью переводов по локалям
- Переводы регистров (языки, автоперевод) скрыты для EN/KZ/IT — контроллер пока поддерживает только RU+EN
- Заголовки групп в таблице регистров отображаются на русском (из `group.translations.ru.title`) при RU-интерфейсе, на английском — при остальных
- Кнопка i18n и блок переводов в GroupManager скрыты при отсутствии поддержки переводов (`useHasTranslations`)

## UX: Hero-блок (пустое состояние)

При пустой таблице вместо тулбара показывается hero-блок из 3 карточек:

1. **Из документа (AI)** — загрузка PDF/Excel/изображений → AI-анализ (акцентная карточка)
2. **Импорт шаблона** — загрузка .json/.json.jinja шаблона wb-mqtt-serial
3. **Вручную / CSV** — добавить регистр или импортировать CSV

Hero-блок поддерживает drag-n-drop с роутингом по расширению: `.json`→импорт шаблона, `.csv`→CSV, остальное→AI.

Тулбар скрыт при пустой таблице. При наличии регистров тулбар содержит только инструменты редактирования (без кнопок «Анализ» и «Импорт шаблона» — они доступны через hero-блок после «Новый шаблон»).

## Тулбар (при наличии регистров)

```
[+ Добавить] [Удалить(N)] | [CSV ▾] | [Группы ⇔] [Языки] | [AI ▾] | ... [Скачать ▾] [Новый шаблон] N рег.
```

- **CSV ▾**: экспорт, импорт, скачать шаблон
- **AI ▾**: автоперевод (по языкам), нормализовать → EN, настройки LLM
- **Скачать ▾**: JSON, Jinja (.json.jinja)

## Нормализация → EN

`NormalizeToEnButton` в `RegisterDetailPanel.tsx` — переводит нелатинский текст в английский с помощью LLM:

- Работает для полей `name` и `description` каждого регистра
- При нажатии: текущий текст сохраняется в `translations.ru` (если переводы включены), основное поле заменяется на английский перевод
- Детекция: `HAS_NON_LATIN` regex — поддерживает кириллицу, казахский, арабский и др.

Массовая нормализация: `store.normalizeToEnglish()` — обрабатывает все регистры и группы с нелатинским текстом, включая enum_entries. Вызывается через AI ▾ → "Нормализовать → EN".

## Автоперевод и языки

- **LanguageManager** — модалка для управления списком языков (сохраняется в localStorage)
- **translateAll(lang)** — пакетный перевод всех пустых полей на указанный язык через LLM
- **propagateEnumTranslation** — при изменении перевода enum-значения обновляет его во всех регистрах с таким же enum title
- Базовый язык — English (en), всегда включён

## CSV импорт/экспорт

Через меню CSV ▾ в тулбаре:
- **Экспорт** — выгрузка текущих регистров в CSV
- **Импорт** — загрузка регистров из CSV (запятая и точка с запятой)
- **Скачать шаблон** — пустой CSV с заголовками

## Drag-n-Drop

- **Перемещение между группами**: `moveRegistersToGroup(regIds, targetGroupId)`
- **Изменение порядка**: `reorderRegister(draggedId, targetId, 'before'|'after')`

## Condition-подсветка

Визуальная связь между каналами и параметрами через condition:

- **При клике**: выделенный регистр — жёлтый (`bg-yellow-100`), связанные через condition — фиолетовые (`bg-purple-50`). Поиск по `name`, `id` и `original_channel_id`.
- **Постоянные бейджи**: фиолетовый — параметр влияет на N каналов; янтарный `?=` — у регистра есть condition.

Condition regex: `(?:^|[^a-zA-Z0-9_])([a-zA-Z_][a-zA-Z0-9_]*?)(?:==|!=|>=|<=|>|<)` — поддерживает `isDefined(param)&&param==1`.

## Jinja-экспорт

`jinja_exporter.py` обнаруживает повторяющиеся структуры и сворачивает в `{% for %}` циклы:

- **Числовые паттерны**: каналы с числом в имени ("Input 1"..."Input 8") и арифметической прогрессией адресов
- **Строковые паттерны**: каналы, различающиеся одним словом в имени → `{% for val in [...] %}`
- **Вариантные каналы (sporadic)**: каналы с одинаковым именем но разными sporadic/condition → вложенный `{% for %}`
- **Переводы (translations)**: повторяющиеся ключи сворачиваются в for-циклы
- **Шаблонизируемые поля**: group, condition — варьирующийся номер заменяется на `{{ i }}`

Минимум 2 элемента для паттерна. Числовые паттерны имеют приоритет над строковыми.
